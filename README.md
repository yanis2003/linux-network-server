#  Mini Serveur Réseau + Linux

Petit serveur réseau permettant de comprendre TCP/IP, sockets, Linux et la configuration Linux.

##  Objectifs
- Créer un mini serveur HTTP (Python ou Node)
- Utiliser les sockets réseau
- Déployer sur un serveur Linux
- Installer et configurer nginx
- Utiliser un script Bash pour automatiser

##  Technologies
- Python ou Node.js
- Linux
- Shell script (Bash)
- Nginx

##  Contenu
- serveur.py
- script Linux d’automatisation
- configuration nginx
